# 课时学情助手

给一对一 / 小班辅导老师用的课时与学情台账。单个 HTML 文件，打开即用，不需要账号、不需要后端。

## 功能

- 学生档案：备考类型、目标院校、考试日期、购买课时、单价、已收款、薄弱模块
- 课时记录：日期、课时数、主题、讲授内容、布置作业、学生状态、回放链接
- 学情归档：亮点、13 类问题标签（漏译 / 术语 / 句式 / 逻辑…）、改进措施、下次重点
- 作业追踪：布置日期、截止日、提交日、批改状态、得分，迟交自动标出
- 自动计算：已用课时、剩余课时、应收 / 待收款；剩余课时不足 5 自动标红
- 自动保存：每次改动立即写入本机，关掉页面不丢
- 导出：CSV（可直接用 Excel 打开）、JSON 备份；支持导入备份迁移到新设备

## 使用

直接打开 `index.html`，或访问 GitHub Pages 地址。

## 数据说明

所有记录保存在浏览器本地（localStorage），不上传任何服务器。换设备时用「数据 → 导出备份」把 JSON 带走，在新设备「导入备份」即可。
清理浏览器缓存会清空记录，重要数据请定期导出备份。
